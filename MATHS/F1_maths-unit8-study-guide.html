Name and measure angles.

  • Name an angle with 3 letters; the middle letter is the vertex: ∠ABC has vertex B.
  • Complementary angles add up to 90° (x = 35° → y = 55°).
  • Supplementary angles add up to 180° (a = 60° → b = 120°).
  • Angle sum of a triangle = 180° [∠ sum of △].
  • Exterior angle of a triangle = sum of the two interior opposite angles [ext. ∠ of △].
Triangle angles 2x + 14, 3x + 9, 2x − 4: 7x + 19 = 180 → x = 23 → angles 60°, 78°, 42°

SHW 8-B1

8B Angles on lines and at a point

180°, 360° and equal opposites.

  • Adjacent angles on a straight line add up to 180° [adj. ∠s on st. line]. 130° + x = 180° → x = 50°.
  • Angles at a point add up to 360° [∠s at a pt.]. x + 100° + 150° = 360° → x = 110°.
  • Vertically opposite angles are equal [vert. opp. ∠s].
On a straight line: 2x + (3x + 5) + (5x − 15) = 180 → 10x = 190 → x = 19
Always write the reason in brackets — teachers give marks for it.

8C–D Parallel lines

Three angle pairs to know.

If AB // CDThenReason
Corresponding angles (F shape)equal[corr. ∠s, AB // CD]
Alternate angles (Z shape)equal[alt. ∠s, AB // CD]
Interior angles (C/U shape)add up to 180°[int. ∠s, AB // CD]
  • Example: alternate angle 65° → x = 65°. Interior angle 100° → x = 80°.

Proving lines are parallel (8D)

  • If corresponding angles are equal → lines are parallel [corr. ∠s equal].
  • If alternate angles are equal → parallel [alt. ∠s equal].
  • If interior angles add up to 180° → parallel [int. ∠s supp.].
  • Example: interior angles 105° and 75° → 105° + 75° = 180° → the lines are parallel.
