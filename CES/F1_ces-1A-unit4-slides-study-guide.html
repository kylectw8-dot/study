簡報 4.1

友誼對個人成長的重要性

情感需求、自我瞭解、社交能力、彼此進步。

青少年在成長過程中，為滿足社交需求，會結識新朋友，拓展社交圈子。

重要性說明
A. 滿足情感需求與年齡和興趣相若的人結成朋友，一起玩樂、分享經驗，組成具歸屬感的群體；情緒欠佳時可得到支持
B. 增進自我瞭解朋友之間地位和權力對等，可以自在表達想法；從朋友的評價和意見中了解自己的優點和缺點
C. 培養社交能力掌握待人接物的技巧；恰當處理和表達情緒；以同理心待人
D. 促進彼此進步各人性格、能力都不同：互相討論、交流分享 → 擴闊視野；學習朋友長處 → 改善個人不足
即時重溫：友誼對青少年個人成長具正面作用，包括滿足情感需求、增進自我瞭解、培養社交能力和促進彼此進步。

簡報 4.2A

友誼的發展歷程（萊文格「關係階段理論」）

相識 → 建立 → 延續 → 衰退 → 結束。

階段特點方法 / 原因
1. 相識注意對方存在，認識限於表面參加社交活動，多與他人接觸；主動介紹自己；態度親切、友善
2. 建立互相交流，逐漸了解，成為朋友找出共同興趣，深入聊天；多溝通了解對方想法和感受
3. 延續真誠交流，互相尊重，信任和依賴定期聯絡；保持良好溝通；以禮相待；欣賞朋友優點，包容缺點；朋友有困難時予以協助
4. 衰退無法溝通，疏於聯絡，發生衝突原因：環境轉變而減少往來；自我中心，忽略朋友需要；缺乏共同興趣和話題；價值觀出現分歧
5. 結束關係未能修補，二人不再聯絡—
  • 友誼的發展是一個漸進而互動的過程，會隨時間而變化。長久真摯的友誼需要彼此付出才能維繫。
  • 維繫友誼的元素：關懷、陪伴、欣賞、包容、尊重、支持、信任、真誠、互助。
  • 此理論參考自德國心理學家喬治・萊文格的「關係階段理論」。

簡報 4.2B、情境題

友誼的廣度和深度（社會滲透理論）

由淺入深的交流。

  • 友誼是朋友間由淺入深的交流發展而成的。
  • 友誼的親密程度與雙方談論話題的廣度（話題的範圍：狹窄 → 廣闊）和深度（話題的內容：表面 → 深入）有密切關係。
  • 知己是最親密的朋友，無所不談，感情深厚。
  • 理論來自美國心理學家歐文・奧爾特曼和達爾馬斯・泰勒的「社會滲透理論」。
即時重溫：友誼的發展階段包括相識、建立、延續、衰退及結束；友誼的親密程度與談論話題的廣度和深度有關。長久的友誼需要雙方付出。

情境題：建立或維繫友誼的方法

情境方法
1. 與朋友少見面平日透過社交媒體聊天，假日主動約見朋友，保持聯絡，以關心彼此近況
2. 只顧說自己避免自我中心，要聆聽和理解對方的想法／需要／感受，令朋友感到受尊重
3. 想認識新同學主動介紹自己或提供協助，打開話匣子，展現平易近人／友善／親切的態度
4. 朋友做錯事與對方坦誠溝通，了解朋友的苦衷，包容朋友的錯誤／過失，並讓對方明白自己的感受／想法

簡報 4.3A–B

朋輩或從眾壓力及應對原則

自我肯定、慎思明辨、遵守法律。

  • 朋輩或從眾壓力：青少年希望獲得朋輩接納，因而願意跟隨朋友的行為。
  • 日常決策（如一起吃甚麼）從眾無礙；但當行為違背自己意願或價值觀，甚至違法（如塗鴉）時，就要作正確決定。

應對的三個原則

原則說明
(1) 自我肯定相信自己的判斷，拒絕跟隨錯誤行為（如作弊、欺凌）
(2) 慎思明辨跟隨朋友行動前，從不同角度（個人方面、人際方面）分析行動的影響；不認同時提出異議，指正不當行為
(3) 遵守法律缺乏守法意識容易做出違法行為而不自知；青少年違法須負上刑責，嚴重影響前途
  • 罪行舉隅：襲擊及毆打、盜竊、侵犯知識產權、危害國家安全。
  • 根據香港法例，刑事責任的最低年齡為十歲。

簡報 4.3C、應用題

應對朋輩壓力的方法

堅定拒絕、離開現場、尋求協助。

方法說明
(1) 堅定拒絕清楚表達意願，明確拒絕：讓對方清楚知道自己的想法；說明自己的立場、意見和感受；眼神專注、神情自信、語調平穩
(2) 離開現場藉故離開，冷靜思考應對方法（例：「現在太晚了，我要回家」、「我感到不適」、「媽媽致電給我」）
(3) 尋求協助向信任的人請教處理方法；切勿因群體壓力胡亂作出決定和行動
即時重溫：當朋友的行為違背自己的意願或價值觀時，應以自我肯定、慎思明辨、遵守法律為原則，並以堅定拒絕、離開現場、尋求協助等方法應對。

應用題（秀妍與哲銘）

個案面對的壓力原則方法回應示例
秀妍考試前一天，詠嵐邀請她一同觀看演唱會，但秀妍想好好温習，以考獲好成績慎思明辨：從不同角度分析——考試成績對學業的長遠影響，以及拒絕對友誼的短期影響堅定拒絕：清楚表達自己的想法，明確拒絕「抱歉，我今晚不能陪你看演唱會。因為我必須在期末考取得佳績才能選修心儀科目……」
哲銘焯然打算在年宵攤位出售盜版貨品；知道違法後仍堅持做法，並希望哲銘支持自我肯定：多數人的意見不一定對，應相信自己的判斷能力尋求協助：將事件告知學會導師「我不贊成……因為這是侵犯知識產權的違法行為，學校聲譽受損，我們也須承擔法律責任。」
回應要：直接表達、具體陳述（原因）、態度堅定。
