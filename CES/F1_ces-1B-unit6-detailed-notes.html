六、資料回應題：志文弟弟的手遊開支

參考答案。

三月結餘 = 收入 2,000 − 支出（770 + 300 + 50 + 3,500 + 0 + 0 = 4,620）= −2,620 元

作業題目（先想答案，再按題目查看）

1. 根據資料 A 和 B，初中及高小學生的消費及理財習慣有甚麼特徵？（4）
消費主要集中在食物、交通、文儀用品等項目（1）；65% 受訪學生沒有記錄儲蓄或用錢的習慣（1）；不少青少年為手遊「課金」，受廣告和促銷吸引（1），甚至擅自使用父母的信用卡，不知不覺多花金錢（1）。
2(i). 計算志文弟弟三月的結餘。（2）
2,000 − 4,620 = −2,620 元
2(ii). 志文弟弟有甚麼理財問題？（1）
入不敷支（支出大於收入），沉迷手遊而過度消費。
2(iii). 弟弟以甚麼方法解決問題？（2）
經常與父母爭吵要求增加零用（1）；甚至偷取長輩的金錢「課金」（1）。
3. 弟弟的消費和理財問題對個人和家庭可能帶來哪些負面影響？（4）
個人：偷錢可能觸犯法律；沉迷手遊影響學業和健康；沒有儲蓄（2）。家庭：與父母爭吵令家庭關係惡化；家人蒙受金錢損失，失去信任（2）。
4. 給予弟弟兩個建議以改善理財問題。（4）
① 制定收支預算，以量入為出為原則，限制手遊開支，並把部分零用儲蓄（2）；② 分清「需要」和「想要」，減少「課金」，並記錄每月收支；如難以控制，可向家人或社工求助（2）。
